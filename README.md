# Bifcode
Bifcode generates side-by-side code comparison images showing Do's and Don'ts. Perfect for documentation, tutorials, code reviews, and technical blog posts. Create clear visual examples of good vs bad practices with syntax highlighting and dark theme. Export high-quality PNGs ready for sharing.

Perfect for:
- Documentation and style guides
- Tutorial content
- Code review illustrations
- Technical blog posts
- Social media developer content

## Features

- 🖼️ Export high-quality PNG images
- 🎨 Syntax highlighting for multiple languages
- 🌙 Dark theme optimized for readability
- ✅ Clear visual Do/Don't indicators
- ⚡ Fast and lightweight
